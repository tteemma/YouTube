# Редактура удержания

## Проверка

| Критерий | Результат |
|---|---|
| Хук | Открывает конкретный вопрос и сразу отсекает упрощение «только солнце». |
| Обещание | Эпизод обещает объяснить географическое решение через причинную цепочку. |
| Контекст | MPPC введена до того, как объясняется её давление; лишней биографии Edison нет. |
| Причинность | Давление на независимых + производственные условия + преимущества места → концентрация компаний. |
| Фактологическая дисциплина | Каждое фактическое предложение привязано к C01–C07; C06 сохраняет обязательную оговорку. |
| Визуализируемость | В каждом абзаце есть документ, сеть, зимняя площадка, карта или контрастные ландшафты. |
| Финал | Возвращает вопрос к многофакторному ответу и меняет значение «солнечного дня». |

## Рекомендация для постановки

Не добавлять на экран тезис «Эдисон преследовал режиссёров» как установленный факт. Патентный конфликт показывать через документы и сеть лицензий, а не через погоню.
