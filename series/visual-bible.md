# Visual Bible

## Format

- Vertical 9:16 composition.
- Strict native pixel art, not a smooth illustration with a pixel-art label.
- Match the visible pixel size and texture of
  `data/Maltipoo _ More Pixelated 1.png`. When that style reference cannot be
  used, simulate a 180x320 logical canvas enlarged 6x with nearest-neighbor
  scaling to 1080x1920.
- Use clearly visible square pixels, one stable pixel grid across the entire
  frame, hard stair-stepped silhouettes, deliberately placed pixel clusters,
  limited color ramps, and pixel dithering instead of smooth gradients.
- Never use anti-aliasing, smooth airbrushed shading, painterly brush texture,
  photographic micro-detail, photorealism, 3D/CGI rendering, or vector-smooth
  edges.
- Brown, amber, charcoal, parchment, and restrained accent colors.
- Clear silhouettes and one dominant visual idea per shot.
- Reserve uncluttered space for editor-added captions.

## Recurring locations and props

Detective archive office, dark wooden desk, warm desk lamp, case files, map,
black magnifying glass, one red thread, sealed letter, and evidence board.

## Shot mix

Use the host, historically grounded reconstructions, maps, documents, and
object close-ups. The host does not need to appear in every shot. Generated
images and clips must not contain final subtitles, dates, labels, logos, or
long readable text.

## Motion

One primary action and one camera behavior per generated clip. Prefer locked
camera, subtle push-in, slow pan, ambient mist, paper movement, or a single
deliberate gesture.
